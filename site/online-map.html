Используем готовый файл карты с GitHub Releases. Он читается прямо в браузере; на наш GitHub Pages игровые данные не загружаются.

Шаг 1 · Готовая карта улиц

Скачать готовую карту ETS2 (.pmtiles, 22,6 МБ) из официального релиза OpenHaul от 03.10.2026. Сам файл проверен на GitHub Actions (формат PMTiles v3, слой ETS2). Наличие всех DLC актуальной версии игры не подтверждено.

Сначала выбери скачанный файл ETS2 .pmtiles.

Шаг 2 · Маршруты (необязательно)

Если у тебя уже есть ets2-routepack.json, можешь добавить его для прокладки маршрутов. Новый поиск файлов игры не нужен. Это прежний приблизительный граф, а не точный GPS ETS2.

Почему не Truck Dash напрямую?

Разработчик Truck Dash публикует отличную готовую карту ETS2 1.62 и дорожный граф, но его собственный сервер доступен только с его сайта. Использовать его как бесплатный CDN для нашего проекта нельзя.

Нужна готовая карта и полноценная маршрутизация сразу? Тогда удобнее попробовать сам Truck Dash. Его карта может быть ближе к игре, чем наша экспериментальная.

Визуальные карты из сторонних релизов могут не совпадать с версией ETS2 или DLC. Не копируй и не публикуй эти файлы на своём сервере без проверки прав SCS Software и авторов карты.
