# ETS2 Atlas

Интерактивная карта Euro Truck Simulator 2 на GitHub Pages без телеметрии.

**Открыть карту:** https://duumbling.github.io/ets_test/

**Запасная PNG-карта:** https://duumbling.github.io/ets_test/raster.html

## Векторная карта подключается автоматически

В основном `index.html` используется MapLibre GL JS и PMTiles. Браузер считывает `assets/ets2.pmtiles` с этого же GitHub Pages-сайта — **ничего скачивать и выбирать вручную не нужно**.

- Векторные дороги, геометрия перекрёстков, подписи городов и POI из OpenHaul.
- Масштаб до 22; линии не размываются из-за растягивания PNG.
- Метки на карте и ссылки на выбранные места.
- Дополнительный `vector.html` работает с тем же встроенным архивом.
- Если встроенная карта недоступна, доступен резервный `raster.html`.

Сам опубликованный PMTiles-архив содержит данные до своего максимального уровня (для проверенного релиза — до 13). При масштабировании свыше него MapLibre перерисовывает существующую векторную геометрию, но **не придумывает новые детали**.

## Как появился файл карты

`.github/workflows/pages.yml` скачивает готовый архив из [релиза OpenHaul](https://github.com/NekoSuneProjects/OpenHaul/releases/tag/map-data), проверяет сигнатуру PMTiles v3 и размер файла, сохраняет его в `assets/ets2.pmtiles` внутри ветки `main` и публикует всё вместе на Pages. Автоматически созданный коммит с картой: [684e90e](https://github.com/duumbling/ets_test/commit/684e90e869ef36bb55e02921a660217b997b770e).

## Ограничения и права

- Это **интерактивная карта**, а не GPS-навигатор с расчётом реальных маршрутов; для маршрутизации нужен отдельный дорожный граф.
- Подключения к игре в реальном времени пока нет.
- Поддержка всех актуальных DLC и модов (включая ProMods/RusMap) не подтверждена.
- Основной сайт и содержимое GitHub Pages **публично доступны**, даже если ими намерен пользоваться только владелец. Личное использование не делает публичное размещение приватным.
- Игровые картографические данные принадлежат SCS Software и, возможно, другим правообладателям. MIT-лицензия кода OpenHaul сама по себе не подтверждает права на дальнейшее публичное распространение данных. При публикации необходимо отдельно учитывать условия правообладателей.
- MapLibre GL JS и PMTiles загружаются из CDN; сам картографический архив — с этого же сайта.

## Для разработчика

Сайт статический. Репозиторий: `duumbling/ets_test`. Публикация через GitHub Actions при изменениях в `main`.

Локальный запуск с файлом карты: `python -m http.server 8000`, затем открыть `http://localhost:8000/`.
