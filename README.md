# ETS2 Atlas — интерактивная карта Euro Truck Simulator 2

**Основной сайт (растровая карта):** https://duumbling.github.io/ets_test/

**Новый векторный просмотрщик:** https://duumbling.github.io/ets_test/vector.html

## Векторная карта — более чёткие дороги

В `vector.html` используется **MapLibre GL JS 5.24.0 + PMTiles 4.5.0**. В отличие от растровых PNG, дорожные линии и геометрия перекрёстков перерисовываются векторно при приближении, а не растягиваются.

1. Открой векторную карту по ссылке выше.
2. Скачай ETS2 PMTiles (около 22,6 МБ) из [релиза OpenHaul](https://github.com/NekoSuneProjects/OpenHaul/releases/tag/map-data).
3. Выбери его в поле `Файл .pmtiles` (или перетащи в карту).
4. Просматривай дороги и города с увеличением **до уровня 22**.

Файл читается через стандартный браузерный File API. Карта сохраняется в IndexedDB браузера, если доступно локальное хранилище. Она **не загружается в GitHub Pages**. Для повторного доступа на том же устройстве в том же браузере карта обычно восстанавливается автоматически.

Векторный архив OpenHaul содержит исходные тайлы только до своего собственного максимального уровня (в проверенном релизе — до 13). На более крупных масштабах геометрия увеличивается векторно, сохраняя чёткие края, но **новых деталей, отсутствующих в исходных данных, не появляется**.

## Растровая карта — запасной режим

`index.html` продолжает отображать PNG-тайлы ETS2 1.62 из [ETS2 Map Toolkit](https://github.com/nulijiazaizhong/ETS2-map-toolkit) в браузере. Доступно перемещение, масштаб до уровня 20, постановка метки, отображение координат и создание ссылок на точки. Исходные PNG ограничены уровнем 8. После этого масштаб растёт за счёт увеличения изображения; режим чётких пикселей уменьшает размытие, но не прибавляет деталей.

## Ограничения и права

- Это **не навигатор с прокладкой маршрутов**: для правильного GPS необходим совместимый направленный дорожный граф.
- Подключение к ETS2 в реальном времени пока не реализовано.
- Полнота текущих DLC и модификаций, включая ProMods/RusMap, не подтверждена.
- Векторный PMTiles-файл не публикуется в этом репозитории и не зеркалируется сервером: он открывается пользователем с устройства, на которое был скачан.
- Игровые данные принадлежат SCS Software и соответствующим правообладателям; лицензии открытого исходного кода не означают разрешения на самостоятельное распространение содержимого игровых карт.
- Для работы веб-приложения нужны внешние CDN MapLibre/PMTiles/Leaflet, а для первой загрузки векторной карты — скачанный файл PMTiles.

## Развёртывание

Статические `index.html` и `vector.html` публикуются через `.github/workflows/pages.yml` при обновлении ветки `main`.

Локальный запуск: `python -m http.server 8000`, затем открыть `http://localhost:8000/`.
