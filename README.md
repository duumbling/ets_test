# ETS2 Atlas
Интерактивная карта ETS2 1.62 (статический сайт, без телеметрии).

**Сайт:** https://duumbling.github.io/ets_test/

## Что работает
- Перемещение и масштабирование реальных PNG-тайлов ETS2 1.62.
- Переключение Европы / TMP (две подложки от ETS2 Map Toolkit).
- Метка по клику, игровые координаты, ссылки на точки.
- Адаптивный интерфейс для компьютера и телефона.

## Источники
Реальные картографические изображения загружаются напрямую из открытого [ETS2 Map Toolkit](https://github.com/nulijiazaizhong/ETS2-map-toolkit) по URL `data/maps/1.62/ETS2/{Europe|TMP}/{z}/{x}/{y}.png`. Сам проект хранит исходные тайлы, а этот репозиторий не зеркалирует игровой контент. Код стороннего проекта распространяется под MIT, но **игровые изображения не предоставляются по MIT**: права на данные принадлежат SCS Software. Использование внешних URL может ограничиваться политикой источника. Для производственной публикации необходимо согласовать право использования и надёжный картографический хостинг.

Карта поддерживает официальные DLC по заявлению автора исходника. Полный набор модов, включая ProMods и RusMap, **не подтверждён**.

## Ограничения
Нет точной маршрутизации по графу, поиска городов и соединения с игрой. Ввод координат и метки не равнозначен навигации по дорогам. Некоторые PNG-тайлы могут не загружаться из GitHub Raw из-за лимитов; карта зависит от сети и стороннего источника.

## Запуск локально
`python -m http.server 8000` и открой `http://localhost:8000`.

Leaflet 1.9.4 подключается через CDN (BSD-2-Clause).
