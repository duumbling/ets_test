# Готовые карты ETS2 без сканирования файлов игры

## Результат проверки от 20 ноября 2026

**Готовые данные существуют, но не все разрешено подгружать с чужого сайта.**

### Truck Dash / Truck Companion

[Проект Truck Dash](https://github.com/Nethercap/truck-companion) действительно подготовил для ETS2 1.62.2.1 векторную карту, бинарный дорожный граф с изгибами, города и POI. Его [публичный манифест](https://github.com/Nethercap/truck-companion/blob/main/docs/data/map-manifest.json) указывает сборку от 10.11.2026, а для ProMods/RusMap — отдельные варианты на ETS2 1.61.

Однако в [README](https://github.com/Nethercap/truck-companion#name-and-logo) прямо указано, что их **карты и relay обслуживают только сайт `trucksim-dash.com` и локальные клиенты автора**. В тесте GitHub Actions запрос к `maps.trucksim-dash.com/ets2/Cities.json` вернул HTTP **403 Forbidden**. Это не публичный CDN для чужих сайтов.

**Мы не встраиваем и не обходим закрытый хостинг Truck Dash.** Если нужен прямо сейчас готовый GPS с их картой и навигацией, пользуйся [их официальным приложением](https://trucksim-dash.com/ru/). Клиент работает с игрой, не требует самостоятельного разбора SCS-архивов и поддерживает карты по версиям, указанным в источнике.

### OpenHaul: скачиваемый файл карты

В [GitHub Releases OpenHaul](https://github.com/NekoSuneProjects/OpenHaul/releases/tag/map-data) есть **готовый ETS2 PMTiles** (от 03.10.2026, около 22,6 МБ), который можно скачать самостоятельно. Код OpenHaul использует MapLibre и тот же класс векторных данных из TruckSim Maps. **Я отдельно проверил скачивание в GitHub Actions:** файл весит **22 590 428 байт**, имеет корректный заголовок PMTiles v3, содержит векторный слой `ets2` и масштабы **1–13**. Это подтверждает пригодность формата, но не полноту всех DLC или точность навигации. [Результаты проверки](https://github.com/duumbling/ets_test/actions/runs/44768567213).

В проекте ETS2 Navigator создана отдельная [страница просмотра готового файла](https://duumbling.github.io/ets_test/online-map.html). Она позволяет открыть скачанный `.pmtiles` из браузера через `PMTiles.FileSource` без загрузки игровых архивов на наш сервер и без обращения к чужому закрытому CDN.

**Ограничения OpenHaul:**
- Релиз содержит карту **для отображения дорог**, но не предоставляет совместимый готовый полный маршрутный граф.
- Полнота всех официальных DLC **не подтверждена** по доступному метаданным релиза. Нельзя гарантировать, что это актуальная карта ETS2 1.62.
- В нашей странице можно дополнительно выбрать уже существующий `ets2-routepack.json` для **приблизительной маршрутизации**. Если файла нет, просмотр доступен без маршрутов.
- Карта хранится в файле на устройстве пользователя, не загружается в репозиторий и не публично раздается с нашего GitHub Pages.

### Другие доступные ресурсы

| Источник | Что есть | Ограничение |
|---|---|---|
| [truckermudgeon/maps](https://github.com/truckermudgeon/maps) | Генератор PMTiles/GeoJSON и маршрутов, все выпущенные на момент исходников официальные map DLC | Нужны файлы установленной игры; сам проект не предоставляет надежно подтвержденного downloadable routepack для актуальной ETS2 |
| [jjwfisher ETS2 + ProMods](https://github.com/jjwfisher/ETS2-ProMods-Map-Tiles) | PNG-тайлы для ETS2 1.50 с DLC того времени и ProMods | Устаревшая версия, нет современного дорожного графа |
| [OpenHaul](https://github.com/NekoSuneProjects/OpenHaul) | Релиз PMTiles, открытый код визуализации | Полнота DLC не доказана, точной маршрутизации из одного PMTiles не получится |
| [Truck Dash](https://trucksim-dash.com/ru/) | Готовый работающий GPS + карты, предварительно собранный дорожный граф | Использовать данные можно только через его официальные страницы/разрешенные сервисы |

## Как пользоваться без сканирования ETS2

1. Открой [релиз OpenHaul](https://github.com/NekoSuneProjects/OpenHaul/releases/tag/map-data).
2. Скачай **ETS2**, а не ATS, файл с расширением `.pmtiles`.
3. Открой [ETS2 Navigator — готовая карта](https://duumbling.github.io/ets_test/online-map.html).
4. Выбери загруженный `.pmtiles`. Он прочитается локально через File API.
5. **Необязательно:** если у тебя уже есть `ets2-routepack.json`, выбери его во втором поле для маршрутов. Старую карту из браузера и твой локальный основной навигатор это не затронет.

## Почему нельзя просто взять «идеальную карту со всеми DLC»

Есть три независимые части: (1) геометрия дорог, (2) направленный дорожный граф, (3) активные DLC/моды конкретного игрового профиля. Один векторный файл с дорогами не гарантирует точные доступные повороты или подъезды к заправкам. Любое смешивание визуального слоя и графа из разных версий может давать расхождения.

Правовая сторона тоже важна: открытая лицензия кода конвертера не означает автоматического разрешения распространять извлеченные игровые данные SCS Software и авторов ProMods. Наш репозиторий не содержит копии этих данных. Для публичной автоматической карты без сканирования лучше использовать собственный легально доступный набор или согласованный с правообладателем источник.

**Статус:** экспериментальная страница использует только выбранные локальные файлы. Совместимость конкретного релиза PMTiles с реальной ETS2 пользователя требует проверки на его браузере и его версии игры.
