# Карты ETS2: базовая, DLC и персональные профили

Сайт: https://duumbling.github.io/ets_test/

## Сохранение и переключение карт

1. Укажи название новой карты, например «ETS2 + мои DLC».
2. Загрузите `ets2-routepack.json` из своей копии ETS2.
3. Сайт сохранит карту в IndexedDB **только в этом браузере и на этом устройстве**. На следующем посещении она откроется автоматически.
4. Чтобы сравнивать карты, импортируй другой JSON под новым именем. Выбирай вариант в поле «Сохранённая карта».
5. Кнопка «Удалить выбранную карту» удаляет только копию, сохранённую в браузере.

Сайт не отправляет файл на GitHub или облачный сервер. Если очистить данные сайта, пользоваться приватным режимом или исчерпать квоту браузера, сохранение может быть недоступно или удалено. Сохраняй исходные JSON-файлы. На другом устройстве карту нужно загрузить отдельно.

## Как создать JSON без терминала

Дважды щёлкни по файлу:

`tools/build_map_windows.cmd`

Он проверит наличие Python, Git, Node.js и npm и запустит сборку карты. При первой установке дополнительно требуются Microsoft Visual C++ Build Tools. Исходные файлы ETS2 не изменяются. Файл будет создан в папке «Загрузки».

С помощью CMD также можно выполнить:

```cmd
cd /d E:\ets_test
tools\build_map_windows.cmd
```

## Базовая ETS2 без дополнений

Чтобы подготовить отдельный вариант **без DLC**, запусти:

```cmd
tools\build_map_windows.cmd --base-only --output "%USERPROFILE%\Downloads\ets2-base.json"
```

Этот режим повторно извлекает только базовую игровую карту. Его нельзя объединять с `--graph-only`: тот режим переиспользует прежние файлы парсера, которые могут содержать DLC.

Обычная сборка читает установленные игровые архивы, включая `dlc*.scs`. **Не нужно считать, что все установленные архивы DLC обязательно доступны текущему игровому профилю.**

## Поддержка картографических модов

**Пока нет автоматической поддержки ProMods и других картографических модов.** Текущий парсер `truckermudgeon/maps` получает архивы из каталога установки ETS2 и не загружает активную конфигурацию модов из выбранного профиля игры. Просто присвоить карте имя «ProMods» недостаточно.

Чтобы сделать моды корректно, следующая версия сборщика должна учитывать приоритеты файлов и порядок наложения активных модов конкретного игрового профиля, затем собирать новый дорожный граф. Форматы и разрешения автора мода требуют отдельных проверок.

## Можно ли сделать твой JSON общедоступной картой?

**Технически да:** файл `site/data/ets2-routepack.json` уже предусмотрен в сайте как автоматически загружаемая карта. Но публикация извлечённых игровых данных в открытом GitHub Pages требует проверки разрешений SCS Software и, если есть моды, их правообладателей. Сборка для личного использования и свободная раздача исходных дорожных данных — разные сценарии.

Кроме того, общая карта из одного комплекта DLC может показывать пользователю отсутствующие у него дороги. Поэтому пока используем локальные профили без публичного размещения личного JSON.
