# Настоящая дорожная сеть ETS2: карта для ETS2 Navigator

**Статус v0.3:** сайт теперь умеет отображать **реальные узлы дорог и города**, вести маршрут по направленному графу, а также показывать положение грузовика в системе координат ETS2. Однако **сами данные игры в репозиторий не включены** — только независимый конвертер. Пока файл не загружен, на сайте остаётся демо-схема. Это не тайловая карта: дороги показываются прямыми линиями между игровыми узлами, без точного изображения изгибов и развязок. Ограничения на повороты у перекрёстков пока обрабатываются упрощённо.

## Как получить файл `ets2-routepack.json`

Нужны: Windows 10/11, установленная **легальная ETS2**, Git, **Node.js 24+**, Python 3.10+, а для сборки нативного парсера — **Visual Studio C++ Build Tools**. Рекомендуем запускать команды из PowerShell. Каталог игры — тот, в котором находятся `base.scs`, `def.scs` и `bin`.

**1. Получи исходники инструмента разбора карты.** Это независимый проект [`truckermudgeon/maps`](https://github.com/truckermudgeon/maps) под GPL-3.0, используемый здесь **как отдельная программа**, а не как часть кода нашего навигатора:

```powershell
git clone --recurse-submodules https://github.com/truckermudgeon/maps.git
cd maps
npm install
npm run build -w packages/clis/parser
```

**2. Сгенерируй JSON из своей установки ETS2.** Замени путь на свой:

```powershell
npx parser -i "C:\Program Files (x86)\Steam\steamapps\common\Euro Truck Simulator 2" -o out/parser
```

Обязательно дождись завершения: нужны файлы `out/parser/europe-nodes.json` и `out/parser/europe-cities.json`. Автор инструмента сообщает, что официальные DLC поддерживаются; сторонние карты, например ProMods, **не поддерживаются**.

**3. Построй направленный дорожный граф.** В той же папке `maps`:

```powershell
npx generator graph -m europe -i out/parser -o out -c
```

Будет создан `out/europe-graph.json`. Если генератор не установился / не запустился, смотри инструкцию в исходном репозитории. Не переименовывай `nodes` в `roads` и не подменяй игровой граф картой обычных европейских дорог.

**4. Создай компактный файл для нашего сайта.** В другом окне PowerShell открой корень своего клона [`duumbling/ets_test`](https://github.com/duumbling/ets_test) и подставь путь к `maps`:

```powershell
py tools/create_ets2_routepack.py --parser-dir "C:\my-projects\maps\out\parser" --graph "C:\my-projects\maps\out\europe-graph.json" --output "ets2-routepack.json"
```

Скрипт не требует дополнительных Python-библиотек; при успехе покажет количество узлов, направленных связей и городов. Этот файл создаётся **локально**, никаких игровых данных скрипт никому не отправляет.

**5. Открой [наш сайт](https://duumbling.github.io/ets_test/)** и в разделе «Настоящие дороги» выбери полученный `ets2-routepack.json`. По карте и городам можно будет строить маршруты в координатах ETS2. Если подключить телеметрию, сайт покажет положение грузовика на этой схеме.

> Внимание: сайт в этой версии **не сохраняет импортированный файл** между перезагрузками страницы: при повторном открытии нужно выбрать файл снова. Если ты владеешь правами на публикацию сформированных данных, можно отдельно положить файл в `site/data/ets2-routepack.json` и сайт загрузит его автоматически. **Не загружай сюда игровые данные для общего доступа без проверки условий использования и разрешения правообладателя.**

## Что именно работает и что пока нет

| Возможность | Статус |
| --- | --- |
| Реальные координаты городов из установленной игры | Да, после импорта |
| Соединение дорожных узлов и выбор пути по графу | Да, упрощённо |
| Соблюдение односторонних направленных рёбер | Да |
| Учёт поворотов, дорожных полос, DLC-требований, пробок, паромов, гаражей | Не полностью: отдельная разработка |
| Красивая карта с изгибами дорог и городскими кварталами | Нет, нужна генерация географических тайлов |
| Маркер грузовика из телеметрии | Да, после подключения телеметрии и карты |
| Отправка маршрута внутрь GPS игры | Нет, официальный Telemetry SDK такого метода не предоставляет |
| Маршрут на публичном сайте без установки игры у пользователя | Пока нет; серверная дистрибуция карт требует отдельного решения |

Для следующей версии можем сделать основу **MapLibre + PMTiles** и специализированный роутинг, а также автозапуск конвертера и добавление поддержки DLC. Картографические тайлы получаются отдельной командой `npx generator map -m europe ...` с установленным `tippecanoe` — подробности в документации [`truckermudgeon/maps`](https://github.com/truckermudgeon/maps).

## Почему мы не включили чужую карту в репозиторий

Картографические данные извлекаются из файлов, защищённых правами SCS Software. Официальный [Game Archive Extractor](https://modding.scssoft.com/wiki/Documentation/Tools/Game_Archive_Extractor) допускает распаковку для разработки модов, однако это само по себе не является разрешением публиковать на GitHub Pages **все извлечённые игровые данные**. Кроме того, исходники генератора `truckermudgeon/maps` распространяются по GPL-3.0. Наш скрипт написан независимо и лишь принимает формат вывода инструментов, не копируя их код. При любом дальнейшем включении чужого кода или данных необходимо соблюдать их лицензии и условия правообладателей.
