# Реальные места ETS2: заправки, ремонт, стоянки и предприятия

С версии Alpha 0.6 навигатор поддерживает **точки интереса (POI)** из самой ETS2.

## Какие места поддерживаются

- Заправки, в том числе на трассах
- Автосервисы / ремонт
- Стоянки / места отдыха
- Весовые станции
- Дилеры грузовиков
- Гаражи
- Кадровые агентства
- Предприятия, склады и места погрузки/разгрузки
- Паромы и железнодорожные терминалы
- Смотровые площадки и достопримечательности

Координаты берутся из реального `europe-pois.json`, который создаёт `truckermudgeon/maps` при разборе файлов игры. Никаких случайных заправок в центре города не создаётся.

## Как обновить существующую карту быстрее всего

Если ты уже запускал наш сборщик и в папке
`C:\Users\XD\ETS2NavigatorTools\maps\out\parser` есть `europe-pois.json`, не нужно заново распаковывать игру.

После обновления двух Python-скриптов из репозитория, запусти в CMD из папки `E:\ets_test`:

```cmd
py tools\build_real_map.py --repack-only
```

Это пересоберёт `ets2-routepack.json` в папке «Загрузки» из уже существующих:
- `europe-nodes.json`
- `europe-cities.json`
- `europe-pois.json`
- `europe-graph.json`

Если `europe-pois.json` отсутствует, сборщик сообщит об этом. Тогда нужен один повторный полный запуск `py tools\build_real_map.py`.

## Как использовать на сайте

1. Открой https://duumbling.github.io/ets_test/ и обнови страницу.
2. Назови профиль «ETS2 с объектами» и загрузи обновлённый JSON.
3. В разделе **«Куда заехать»** выбери категорию «Заправки» или «Ремонт».
4. Нажми на конкретное место — оно станет пунктом назначения, сайт приблизит карту и построит маршрут.
5. При увеличении масштаба до 1,8× появляются значки объектов. На них тоже можно нажимать.
6. Последний загруженный файл сохранится в браузере, исходный старый профиль можно удалить через селектор карт.

Старые файлы карты (до версии 0.6) остаются совместимыми, но не содержат POI. При их открытии интерфейс честно покажет, что объектов нет.

## Ограничение маршрутов к конкретной заправке

Маршрут привязывается к дорожному графу. Если POI содержит прямую ссылку на дорожный узел, используется она; иначе выбирается ближайший узел по координатам.

**Это пока приблизительный подъезд, а не гарантированный точный путь прямо к колонке заправки.** Для точной навигации по парковке, развязке, сервисной зоне и правилам поворотов необходима более подробная топология игровых префабов. Вблизи некоторых объектов маршрут может заканчиваться на дороге рядом, а не внутри территории. Не все POI гарантированно доступны из любой части направленного графа.

## DLC и моды

Объекты берутся из тех игровых архивов и DLC, которые смог прочитать сборщик, как и дорожная сеть. Автоматическое чтение активного набора картографических модов игрового профиля, включая ProMods, пока не реализовано. Если карта с модами не собрана, их POI не появятся.

Данные сохраняются в IndexedDB только на устройстве игрока и не загружаются в GitHub.
